# Beauty Store E-Commerce Web Application

This project is a full-stack web-based e-commerce application developed using PHP. It simulates an online beauty store where users can browse products, manage their cart, and place orders.

The system also includes an admin panel for product management.

## Overview

The application provides a complete online shopping experience, including:

* User registration and login
* Product browsing and category filtering
* Search functionality
* Shopping cart management
* Checkout and order placement
* Order confirmation system

## Features

### User Features

* User authentication (register, login, logout)
* Browse products by category
* View product details
* Add/remove products from cart
* Update cart quantity
* Search for products
* Place orders and view confirmation

### Admin Features

* Add new products
* Manage product listings
* Control store inventory

## Technologies Used

* PHP
* HTML, CSS
* MySQL (database)
* JavaScript (basic interactions)

## Project Structure

* `index.php` – homepage
* `products.php` – product listing
* `product_detail.php` – product details
* `cart.php` – shopping cart
* `checkout.php` – checkout system
* `login.php / register.php` – authentication
* `admin/` – admin panel (product management)

## How to Run

1. Install XAMPP or any local server
2. Place the project folder inside `htdocs`
3. Start Apache and MySQL
4. Import the database into phpMyAdmin
5. Open in browser:
   http://localhost/beauty_store

## Results

The system successfully simulates an online shopping platform with full user interaction, including cart operations and order processing.
